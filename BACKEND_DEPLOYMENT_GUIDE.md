# 🔧 Backend Deployment Guide - Railway/Render

## 🎯 Overview

Since cPanel has limited Node.js support, we'll deploy the NestJS backend to a Node.js hosting service. This guide covers **Railway** (recommended) and **Render** as alternative options.

---

## 🚀 Option A: Railway Deployment (Recommended)

### Why Railway?
- ✅ Free tier available
- ✅ Auto-deploys from GitHub
- ✅ Built-in PostgreSQL
- ✅ Easy SSL certificates
- ✅ Good performance

### Step 1: Create Railway Account
1. Go to [railway.app](https://railway.app)
2. Click "Login with GitHub"
3.Authorize GitHub access

### Step 2: Create New Project
1. Click "New Project"
2. Select "Deploy from GitHub repo"
3. Choose your repository: `cento-ecommerce`

### Step 3: Configure Backend Service
1. Click "Add Service" → "GitHub Repo"
2. Select your repository
3. **Root Directory**: Set to `backend`
4. **Start Command**: `npm run start:prod`
5. Click "Deploy"

Railway will auto-detect NestJS and configure accordingly.

### Step 4: Add PostgreSQL Database
1. In your Railway project, click "Add Service"
2. Select "Database" → "PostgreSQL"
3. Railway will create a database

### Step 5: Configure Environment Variables
Go to your backend service → "Variables" tab:

```env
NODE_ENV=production
PORT=4000
DATABASE_URL=postgresql://... (auto-generated by Railway)
JWT_ACCESS_SECRET=your_secret_here
JWT_REFRESH_SECRET=your_secret_here
JWT_ACCESS_EXPIRES_IN=15m
JWT_REFRESH_EXPIRES_IN=7d
CORS_ORIGIN=https://admin.cento-servizi.it

# Email (optional)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password
MAIL_FROM=Cento Admin <no-reply@cento-servizi.it>
```

### Step 6: Run Database Migrations
1. Go to your backend service in Railway
2. Click "Deployments" tab
3. Click "More" → "Open Console"
4. Run: `npx prisma migrate deploy`
5. Run: `npx prisma db seed`

### Step 7: Get Your Backend URL
1. Go to your backend service
2. Click "Settings" → "Networking"
3. Copy the generated URL: `https://your-backend.railway.app`

### Step 8: Update Frontend API URL
In your frontend `.env.production`:
```env
NEXT_PUBLIC_API_URL=https://your-backend.railway.app/api
```

### Step 9: Test Backend API
```bash
# Health check
curl https://your-backend.railway.app/api/health

# API documentation
https://your-backend.railway.app/api/docs
```

## 🎨 Option B: Render Deployment (Alternative)

### Why Render?
- ✅ Free tier available
- ✅ Auto-deploys from GitHub
- ✅ Easy SSL certificates
- ✅ Good documentation

### Step 1: Create Render Account
1. Go to [render.com](https://render.com)
2. Click "Sign Up with GitHub"

### Step 2: Create New Web Service
1. Click "New" → "Web Service"
2. Connect your GitHub repository
3. Configure:

**Name**: `cento-backend-api`
**Root Directory**: `backend`
**Build Command**: `npm install && npm run build`
**Start Command**: `npm run start:prod`
**Environment**: Node

### Step 3: Add PostgreSQL Database
1. Click "New" → "PostgreSQL"
2. Choose free tier
3. Copy the "Internal Database URL"

### Step 4: Configure Environment Variables
In your web service → "Environment" tab:

```env
DATABASE_URL=your_render_postgres_url
NODE_ENV=production
PORT=4000
# ... other variables (same as Railway)
```

### Step 5: Deploy and Test
1. Click "Create Web Service"
2. Wait for deployment (~5-10 minutes)
3. Test your backend URL

## 🔐 Generate JWT Secrets

Run these commands to generate secure secrets:

```bash
# Generate access token secret
openssl rand -base64 48

# Generate refresh token secret (different one)
openssl rand -base64 48
```

Use these for:
- `JWT_ACCESS_SECRET`
- `JWT_REFRESH_SECRET`

## 📧 Email Configuration

### Option A: Gmail (Free)
1. Enable 2-Step Verification
2. Create App Password: https://myaccount.google.com/apppasswords
3. Use these settings:
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-16-char-app-password
```

1. Create account: [sendgrid.com](https://sendgrid.com)
2. Create API Key
3. Use these settings:
```env
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASSWORD=your_sendgrid_api_key
```

## 🌐 Custom Domain Setup (Optional)

### For Backend API
1. In Railway/Render, go to service settings
2. Add custom domain: `api.cento-servizi.it`
3. Update DNS records (service will provide instructions)

### DNS Configuration
```
Type: CNAME
Name: api
Value: your-backend-url.railway.app
TTL: 3600
```

## 🔍 Troubleshooting

### Build Failures
- Check Node.js version (should be 18+)
- Verify all dependencies in package.json
- Check build logs in Railway/Render

### Database Connection Issues
- Verify DATABASE_URL format
- Check database service is running
- Test connection string manually

### CORS Errors
- Verify CORS_ORIGIN includes frontend domain
- Check backend is running
- Verify API URL is correct

### Email Not Working
- Verify SMTP credentials
- Check SMTP_HOST and SMTP_PORT
- Test SMTP connection manually
